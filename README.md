# Баяндун — Хойд хэсгийн 8 га төлөвлөлт

Дорнод аймаг, Баяндун сумын (код 02104) хойд хэсгийн 8 га газрын нэгж талбарын хуваалт, гудамжны сүлжээ, газрын баланс.

## Бүтэц
```
data/raw/parcels_4326.json   egazar WFS-ээс татсан одоо байгаа нэгж талбар (geo_view_parcel_soum_egazar)
data/site_boundary.geojson   төлөвлөлтийн хил (8 га) + ноорог 2, ноорог 1; properties.utm49 = EPSG:32649
data/sketch3_inputs.json     ноорог 2 (зураг 3) ба шороон замын тэнхлэг, UTM 49N
data/dirt_road.geojson       зүүн талын шороон зам (зураг 3-аас тойм зурсан)
scripts/georef_overlay.py    ноорог зураг дээр нэгж талбар давхарлаж геолавлалт шалгах
scripts/sketch_to_boundary.py ноорог 1 (зураг 2)-ийг координат руу хөрвүүлэх
scripts/sketch3_inputs.py    ноорог 2 (зураг 3) ба шороон замыг координат руу хөрвүүлэх
web/scripts/design-site.mjs  8 га-ийн хилийг сонгох хайлт (доорх «Хил»-ийг үз)
outputs/                     анхны хувилбарын GeoJSON / CSV / DXF
web/                         Next.js 16 апп — Бөөрөлжүүт-ын Portal бүтэц, нэг ArcGIS JS SDK газрын зураг (2D/3D)
```

## Апп-ын хэсгүүд
- **01 Нэгж талбарын хуваалт** — `web/lib/plan.ts`, `web/components/Workspace.tsx`; давхарга `mod:1:*` (зөвхөн хүрээ, дүүргэлтгүй).
- **02 Суурьшлын бүсийн загвар** — Бөөрөлжүүт-ын «Суурьшлын бүсийн загвар тооцоолох» (`components/sections/UrbanPlan.tsx`
  ба түүний хамаарал 65 файл, `I:\Booroljuut\web`-ээс хуулсан). Ажиллах зарчим Бөөрөлжүүт-тай ижил: хүн амын хөтөлбөр → тэнхлэг →
  бүсчлэл → блок → барилга (2D/3D) → ногоон → явган → инженерийн шугам → ИБАХ → төсөв, Terrain3D DEM.

02-ын **«8 га-д систем өөрөө»** горим (`web/lib/soumPlan.ts`, `web/components/sections/SoumPlanner.tsx`, давхарга `mod:3:sp-*`)
нь Бөөрөлжүүт-ын алхмыг сумын амины байшинтай хороололд дахин бичсэн: хөтөлбөр (хүн ам → өрх) → анхдагчаар 2,000 м² (40 × 50 м)
хашаатай 1/2 эгнээний хувилбаруудыг `runPlan`-аар харьцуулна → хойд/баруун захад салхины
хамгаалалтын зурвас → тоглоомын талбайг гаргана; цэцэрлэг, худалдаа, инженерийн талбайд газар нөөцлөхгүй, айлын хашаанд ашиглана
→ `parcelYards.ts`-ийн ижил геометрээр 6 төрлийн байшин, залгаа/тусдаа гараж, нэг машин, хашааны зам, мод, цэцэг байрлуулна
→ ус/цахилгааны шугам гудамжны тэнхлэгээр → төсөв, нормын шалгалт (ТААМАГЛАЛ). Горимыг нээхэд бүх төлөвлөлт шууд харагдана.
Шалгалт: `node --experimental-strip-types --test web/scripts/soum.test.mjs`.

02-ын **«Айл бүрт · 2,000 м²»** горим нь `lib/parcelYards.ts`-ийн метрийн геометрээр 6 өөр амины байшин
(гэр бүлийн, L хэлбэрийн, модерн, террастай, компакт, хоёр давхар) хольж байрлуулна. Айл бүрийн байшингийн төрөл,
залгаа гараж / тусдаа гараж / ил зогсоолыг самбараас тусад нь сонгоно. Нэг айлд нэг машин: машин 1.8 × 4.5 м (8.1 м²),
гараж 4.5 × 7 м (31.5 м²), ил зогсоол 2.8 × 5.5 м (15.4 м²); хашаа 40 × 50 м (2,000 м²).
Хаалга, орц нь гаражийн байрлалыг дагана. Хашааны хэсгүүдийн дугаар 1–7, 9, 10 (усны савны 8-ыг хассан).
2D газрын зураг, хашааны жишиг зураг, 3D барилгууд ижил геометр ашиглана; хэмжээнүүд нь жишиг төлөвлөлт.

Бөөрөлжүүт-аас өөрчилсөн зүйл (бусад нь хэвээр):
| Файл | Өөрчлөлт |
|---|---|
| бүх хуулсан файл | EPSG:32648 → 32649 (UTM 49N, Баяндун 113.36°E) |
| `lib/layers.ts` | ArcGIS Online сервисийн оронд локал `/api/site/FeatureServer`; давхарга: бүс (41), шороон зам (25), egazar нэгж талбар (50) |
| `app/api/site/FeatureServer` | шинэ — `lib/siteData.json` болон egazar өгөгдлийг ArcGIS REST Query хэлбэрээр өгнө |
| `lib/masterplan.ts` | 16 бүс шаардахгүй — зөвхөн суурьшлын бүс (ID 1) |
| `lib/corridors.ts` | DEM-ийн хүрээ төслийн хилээр; байхгүй бүсийн холбоосыг алгасна; одоогийн замын зурвас 24 м |
| `components/PlanningContext.tsx` | замын сүлжээний DEM 30 м (Бөөрөлжүүт 100 м) |
| `lib/urban.ts` | анхдагч параметр 8 га-д: 500 хүн, 4 давхар, гудамж 20/15/12 м, блок 6,000 м², ажлын байр 0 |

(`scripts/build-site-data.mjs`). Хил шинэчилсний дараа: `node scripts/design-site.mjs && node scripts/build-site-data.mjs`.

## Хил (`web/scripts/design-site-neighbor.mjs`)
Ноорог нь ойролцоо байршил (ноорог 1 ≈5.8 га, ноорог 2 ≈11.0 га). Хэрэглэгчийн шаардлага:
- урд талын хөрш (2112002039-ийн бүлэг, 55.5°)-ийн чиглэлтэй, урд тал нь хөршийн дэргэд (≤25 м), 8 га хүрэхгүй хэсгийг хойш сунгана;
- зүүн хил шороон замын тэнхлэгээс 35 м (нооргуудад 32–40 м) — замыг давахгүй;
- одоо байгаа нэгж талбараас 10 м; хөршийн буфер хоорондох нарийн сэрээг тайрна.
Хайлт нь бүлгийн чиглэлтэй тэгш өнцөгтийн байрлал/харьцааг туршиж, хамгийн их орон сууцны талбай өгөхийг сонгоно.
Хөршийн бүлгүүд (`lib/neighbors.ts`): 39.2° (баруун урд урт эгнээ), 55.5° (урд, эгнээ 64.1 м), 60.1°, 17°.
Гурван хувилбар (апп-д «8 га хувилбар 1/2/3», апп хувилбар 1-ээр нээгдэнэ):
- **Хувилбар 1** — `design-site-v3.mjs`: хэрэглэгчийн урт тэгш өнцөгт ноорог (`data/raw/sketch_v3b.jpg` → `scripts/sketch_v3b.py`,
  ≈685×201 м) дотор 435×184 м тэгш өнцөгт, 39.2° (хөршийн бүлэг 2112002131), нэгж талбараас ≥10 м, цэнхэр толбоос аль болох хол.
  2026-10-27-нд хуучин хувилбар 1-тэй байраа сольсон (тиймээс скриптийн нэр `-v3`).
- **Хувилбар 2** — `design-site-rect.mjs`: хөршийн чиглэлтэй, нэг хонхортой 6 оройтой хэлбэр, өндөр нь эгнээний тоогоор (эгнээ хилд яг тулна).
- **Хувилбар 3** (хуучин 1) — `design-site-neighbor.mjs` (хөршийн буфераар хайчилсан) → `data/site_boundary_v1.geojson`, баруун хойд буланг
  хэрэглэгчийн шугамаар (гудамжны шугам) тэгшилж 8 га-г нөхсөн: `refine-v1.mjs`.
Дахин үүсгэх дараалал (`web`-ээс): `design-site-neighbor.mjs` → гарсан эхний объектыг `data/site_boundary_v1.geojson` болгох →
`design-site-rect.mjs` → `refine-v1.mjs` → `design-site-v3.mjs` → `build-site-data.mjs`.

## Нэгж талбар
- Хэмжээ: 700 / 2,000 / 4,000 / 5,000 м² (700 м² нь хөрш egazar нэгж талбартай ижил 20×35 м; бусад нь гүн 50 м, нүүр 40/80/100 м; холимог горимд бүгд 50 м гүнтэй тул 700 м² = 14×50 м), талбайн зорилтот хувь 20/40/20/20%.
- Зөвхөн бүтэн талбар — хилээр тайрагдсан хэсэг ногоон байгууламж болно.
- Эгнээ бүр өөрийн гудамжтай (50 м + 14.1 м = хөршийн 64.1 м давтамж), эгнээ хөршийн эгнээний шугамын үргэлжлэл (`anchor`).

## Төлөвлөлтийн арга (`web/lib/plan.ts`)
1. Хилийг гудамжны чиглэлд эргүүлнэ (анхдагч нь хөршийн бүлгийн чиглэл; `anchor` өгвөл эгнээг хөрштэй нэг шугамд тавина).
2. Гол гудамжийг талбайн төвөөр, түүнээс дээш/доош 2 эгнээ нэгж талбартай блок, туслах гудамж давтагдана; блокийн урт = нэг эгнээний талбарын тоо × нүүр.
3. Нэгж талбарыг хилээр тайрч, тогтоосон хувиас (анхдагч 80%) бага болон гудамжинд гарцгүй хэсгийг ногоон байгууламжид шилжүүлнэ.
4. Торын шилжилтийг 10×10 хувилбараар хайж хамгийн олон бүтэн талбар өгөхийг сонгоно.
5. Гол гудамжинд залгасан, төвд ойр бүтэн талбаруудыг нэгтгэж нийтийн зориулалтад нөөцөлнө.

## Таамаглал ба шалгах зүйл
- **ТААМАГЛАЛ:** шороон замын тэнхлэгээс 35 м, одоо байгаа нэгж талбараас 10 м зай. Ноорог, замын геолавлалтын алдаа ±5 м.
- **ТААМАГЛАЛ:** гүн 50 м, гудамж 14.1 м — хөрш нэгж талбартай ижил. Гол гудамж 20 м.
- **ШАЛГАХ:** гудамжны улаан шугамын өргөн — БНбД 30-01-04; сумын ерөнхий төлөвлөгөө.
- **ШАЛГАХ:** координат WGS84 / UTM 49N. Кадастрын бүртгэлд оруулахын өмнө газар дээр хэмжилт хийж, шаардлагатай системд хөрвүүлнэ.
- Хиймэл дагуулын зураг: Esri World Imagery (энэ нутагт z17 хүртэл).
